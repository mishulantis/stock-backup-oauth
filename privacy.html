Privacy policy

STOCK Desktop Backup · Effective October 20, 2026

Purpose and access

This personal automation uses Google Drive authorization to upload, list, download, verify, and manage the operator's own backups. The requested Drive permission can allow access beyond the configured backup folders; the backup workflow targets its configured backup location.

Data handling

Backup contents and file metadata are processed on the operator's computer and stored in the operator's Google Drive. OAuth credentials are used for authentication and are not published on this website. Google user data is not sold, used for advertising, or used to train AI models by this backup application.

Retention and control

The configured backup policy retains two complete backup generations and their associated increments. Temporary work files are cleaned after successful completion; a pending backup may be retained to resume after an interruption. The operator can revoke the application's access in Google Account settings and manage stored backups in Google Drive. Revoking access does not itself delete existing backups.

Services and website

Google Drive provides the storage and authorization service. This informational website is hosted on GitHub Pages and contains no backup data or login form. Hosting providers may process ordinary request metadata under their own privacy policies.

Google API data use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For application questions, contact the operator through GitHub. Do not post credentials or backup contents in public issues.

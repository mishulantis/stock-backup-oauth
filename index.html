STOCK Desktop Backup

A personal desktop automation for backing up the operator's own STOCK project data to the operator's Google Drive, using rclone.

The automation creates full and incremental backups, verifies uploaded content, and removes expired backup generations according to its configured retention policy. It is not a public file-storage or account-registration service.

This website serves only as application information for Google OAuth. It contains no backup files and does not collect Google credentials.
